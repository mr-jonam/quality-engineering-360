## Rationale and alternatives

The owner expressly selected all rights reserved and commercial contact only,
without donation links. CC BY 4.0 was considered for documentation/media and
declined because broad reuse is not the owner's objective. A software licence
such as MIT or Apache-2.0 is not selected for a documentation/artwork portfolio.
No external contributions are solicited; a future contribution model requires
an explicit rights review. No patent, database, hardware or model-weight grant
is part of this project.

The original work can be read publicly. Reuse beyond applicable law and platform
terms requires permission. Public GitHub hosting still permits viewing and
forking within GitHub under its terms. No custom notice overrides those terms.
